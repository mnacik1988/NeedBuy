# NeedBuy

Список покупок голосом. Скажи или напиши «2 кг яблок, молоко и хлеб» — приложение
разложит товары по отделам магазина и покажет картинку каждого.

## Что внутри

| Файл | Зачем |
|---|---|
| `index.html` | всё приложение: интерфейс, разбор фраз, хранение, голос |
| `catalog.js` | каталог товаров: основы слов на 5 языках → товар, отдел, единица |
| `icons.js` | иллюстрации товаров в SVG |
| `sw.js` | офлайн-оболочка (сеть → кэш) |
| `manifest.json` | PWA-манифест |

## Иллюстрации

Все картинки нарисованы с нуля для этого проекта — в SVG, прямо в `icons.js`.
Ни одного стороннего набора, ни одной чужой фотографии: вопрос авторских прав
закрыт полностью, атрибуция не нужна. Побочная выгода — вес в килобайтах,
прозрачный фон (работают на любой теме), масштаб без потери качества, офлайн.

## Разбор фраз

Пока без ИИ, локально:

- количество и единица — «2 кг яблок», «яблоки 2 кг», «два банана», «полкило сыра»
- несколько товаров в одной фразе — по запятым и союзам «и / і / та / and / und / et»
- срезаются командные слова — «купить», «нужно», «добавь», «buy», «kaufen»
- товар опознаётся по ОСНОВЕ слова, поэтому падежи не мешают: «яблок» ← «яблоки», «яблоками»
- если сказано ровно название товара, на плитке показывается витринное имя
  («яблок» → «Яблоки»); если добавлено уточнение — остаются слова человека
  («куриное филе» так и останется, но с картинкой курицы)

Разбор через Claude подключится, когда появится воркер NeedBuy — константа
`WORKER_URL` в `index.html` пока пустая.

## Языки

ru, en, uk, de, fr — интерфейс, каталог и язык голоса (язык голоса настраивается
отдельно от интерфейса).

## Версии

Три части: `1.0.0` — релиз, `0.6.0` — заметный блок функций, `0.5.1` — обычная правка.
Поднимать только скриптом:

```
python release.py           # 0.5.1 -> 0.5.2
python release.py minor     # 0.5.2 -> 0.6.0
python release.py major     # 0.6.0 -> 1.0.0
```

Номер живёт в двух местах — `APP_VERSION` в index.html и `CACHE_NAME` в sw.js.
Если поднять только первый, браузер продолжит отдавать старые файлы из кэша и
правка не доедет до телефона. Скрипт двигает оба сразу.

## Локальный запуск

```
python -m http.server 3470 --directory .
```
